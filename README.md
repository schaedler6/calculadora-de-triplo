# Calculadora de Triplo

Este projeto é uma calculadora simples desenvolvida em Python utilizando a biblioteca Tkinter. O objetivo é calcular o **triplo** de um número inserido pelo usuário.

## 🖥️ Funcionalidades
✅ Interface gráfica com Tkinter  
✅ Design com fundo preto fosco e texto azul neon  
✅ Cálculo correto do triplo de um número  
✅ Tratamento de erros para entradas inválidas
